Keyboard Hero Dokumentace

Kompletní technická a uživatelská dokumentace k webové aplikaci pro žáky a učitele ZUŠ Moravský Krumlov.

O aplikaci

Keyboard Hero je webová aplikace vyvinutá pro žáky Základní umělecké školy Moravský Krumlov. Jejím hlavním cílem je hravou a motivující formou vést děti k pravidelnému domácímu cvičení na hudební nástroj.

Princip fungování: Žák nahraje svá cvičení přímo v prohlížeči, buduje si cvičební řadu, sbírá hvězdy za účast na koncertě (spravuje učitel) a dostává zpětnou vazbu přímo od učitele. Učitel má samostatné rozhraní pro správu výsledků a poslech nahrávek.

Odznáčky a ukazatele

V horním panelu rozhraní žáka se zobrazují metriky jeho cvičebního pokroku:

🔥

Denní řada (Streak)

Počet po sobě jdoucích dní, kdy žák odeslal alespoň jedno cvičení.

🎵

Odesláno

Celkový počet nahraných a úspěšně doručených nahrávek cvičení.

⭐

Koncerty

Hvězdičky udělované učitelem za výkony na koncertech.

Uživatelská příručka pro žáka

1. Registrace a přihlášení

  • Registrace: Při prvním spuštění klikněte na Chci se zaregistrovat, vyplňte uživatelské jméno bez diakritiky (např. jannovak), celé jméno a heslo.
  • Přihlášení: Zadejte uživatelské jméno a heslo. Volba Zapamatovat si mě vás udrží přihlášené i po zavření prohlížeče.
Důležité: Uživatelské jméno nesmí obsahovat diakritiku ani mezery, slouží totiž k vygenerování interního e-mailu (jannovak@keyboardhero.internal).

2. Funkce v rozhraní žáka

Funkce Popis a návod
🎙️ Nahrávání cvičení Stiskněte tlačítko s mikrofonem. Tlačítko červeně pulzuje. Po dokončení hraní opět stiskněte tlačítko – nahrávka se automaticky nahraje učiteli a tlačítko se rozsvítí zeleně.
🎼 Měsíční kalendář Zobrazuje dny v daném měsíci. Dny, kdy bylo nahráno cvičení, jsou zvýrazněny oranžovo-červeným gradientem.
💾 Nedávné nahrávky Přehled až 5 posledních nahrávek s možností přehrání nebo stažení do zařízení (tlačítkem 💾).
💬 Komentáře učitele Zobrazuje zpětnou vazbu a poznámky, které vám učitel napsal k vašim nahrávkám.
🏆 Žebříček (Top Žáci) Soutěžní tabulka nejlepších žáků seřazená podle denní řady (🔥) a počtu hvězd (⭐).
Upozornění k nahrávkám: Starší audio soubory se z důvodu úspory místa průběžně mažou.
Pokud si chcete své cvičení uchovat, stáhněte si ho včas přes tlačítko 💾.

Uživatelská příručka pro administrátora

Administrátorský panel slouží učitelům k poslechům nahrávek, psaní hodnocení a správě statistik žáků.

Možnosti administrátora

  1. Přihlášení: Přístup přes tlačítko Admin Login nebo soubor admin.html. Nutné účty s rolí admin.
  2. Správa bodů a odznáčků: V přehledné tabulce žáků lze tlačítky + a - okamžitě upravit hodnoty Streak a Stars. Změny se uloží tlačítkem Uložit.
  3. Poslech a komentování: Po kliknutí na tlačítko Nahrávky u daného žáka se otevře panel se všemi jeho zvukovými záznamy. Učitel si může skladbu přehrát a napsat k ní slovní komentář.
  4. Mazání nahrávek: Tlačítko 🗑️ Smazat trvale odstraní nahrávku jak z databáze, tak z úložiště Supabase Storage.

Architektura

Aplikace je postavena na moderních webových standardech bez nutnosti kompilace či těžkých JavaScriptových frameworků.

Použité technologie

  • Frontend: HTML5, CSS3 (Flexbox/Grid), Vanillajs, Web Audio / MediaRecorder API.
  • Backend & Databáze: Supabase (PostgreSQL, Authentication, Storage).
  • Audio Formát: standardní audio/wav Blob streamovaný z mikrofonu zařízení.

Databázové tabulky (Supabase Schema)

-- Profily uživatelů
profiles (
  id uuid PRIMARY KEY REFERENCES auth.users,
  username text,
  full_name text,
  role text DEFAULT 'student',
  streak integer DEFAULT 0,
  stars integer DEFAULT 0
);

-- Záznamy o cvičení
practice_logs (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id uuid REFERENCES profiles(id),
  audio_url text,
  teacher_comment text,
  created_at timestamp with time zone DEFAULT now()
);

Interní autentizační logika

Jelikož děti v ZUŠ často nemají vlastní e-mailové adresy, aplikace automaticky převádí uživatelské jméno na vnitřní e-mailový tvar:

function makeInternalEmail(username) {
  const cleanUsername = username.trim().toLowerCase().replace(/\s+/g, '');
  return `${cleanUsername}@keyboardhero.internal`;
}
